## AMI (Amazon Machine Image)
Are customized images that are used to launch EC2 instances. This is a similar concept than images in Docker.

* They AMI are region specific.
* They are stored in S3
* They come with EBS attached.

## AMI Image Builder
It's a service that simplifies the creation, maintenance, validation, sharing, and deployment of Linux or Windows Server images.

* It's a fully managed service.
* The billing is based on underlying resources.
