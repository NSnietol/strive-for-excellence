## Elastic File System (EFS)

It's a scalable, elastic, cloud-native file system for Linux-based workloads for use with AWS Cloud services and on-premises resources and is multi-AZ.


## EFS Infrequent Access (EFS IA)

It's a storage class that is designed for files that are accessed less frequently, but require rapid access when needed. It's a cost-optimized storage class for files that are not accessed every day.



## Amazon FSx

Launch 3rd party file systems in the cloud. It's a fully managed service that makes it easy to launch and run popular file systems that are fully compatible with your applications.

- **FSx for Luster** : It's a high-performance file system optimized for workloads such as machine learning, high-performance computing, video processing, financial modeling, electronic design automation, and analytics.
- **FSx for Windows File Server** : It provides fully managed, highly reliable file storage that is accessible over the Server Message Block (SMB) protocol. It's built on Windows Server.
